# Baseline

This directory stores the known failures and measurements used as the current
regression baseline.

Run the complete baseline refresh with:

```sh
npm run baseline
```

Run the suite without updating the baseline with:

```sh
npm test
```

`SUMMARY.md` is generated by `npm run baseline:summary`. The JSON files beside it
are the machine-readable source of truth used to distinguish known defects from
new regressions. `measurements/` stores informational values such as page
resource weights and validation counts.

The baseline must not be updated to make an unexplained test pass. Update it only
when the change in findings is deliberate and reviewed.
